# Telegram-бот для записи клиентов

Бот регистрирует клиента, показывает свободное время, создаёт и отменяет
записи, уведомляет мастера и отправляет напоминания клиенту и мастеру.

## Возможности

- регистрация по ФИО и телефону;
- показ только будущих свободных слотов;
- атомарное бронирование без двойной записи;
- не более одной будущей записи на клиента;
- дневной лимит записей;
- отмена с освобождением правильного слота;
- добавление нескольких слотов одной командой мастера;
- восстановление будущих напоминаний после перезапуска;
- сохранение входящих сообщений и ответов бота в SQLite;
- хранение токена и настроек вне исходного кода.

## Требования

- Python 3.11 или новее;
- токен Telegram-бота от `@BotFather`;
- Telegram ID мастера.

## Установка в Windows

Откройте PowerShell в папке проекта:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e .
Copy-Item .env.example .env
```

Откройте `.env` и заполните:

```dotenv
BOT_TOKEN=ваш_токен
MASTER_TELEGRAM_ID=ваш_telegram_id
```

Запустите:

```powershell
python run.py
```

При первом запуске база автоматически создастся в `data/database.db`, а журнал
работы — в `logs/bot.log`.

## Журнал диалогов

Каждое входящее сообщение и каждый успешно отправленный текстовый ответ
сохраняются в таблице `dialog_messages` базы `data/database.db`.

Для входящих сообщений сохраняются:

- Telegram ID, chat ID и username пользователя;
- имя и фамилия из профиля Telegram;
- текст или подпись к вложению;
- тип сообщения;
- ID сообщения и события Telegram;
- дата и время;
- направление `incoming`.

Ответы бота сохраняются с направлением `outgoing`. Ошибка журналирования
записывается в технический лог, но не блокирует работу диалога.

## Команды клиента

- `/start` — регистрация и выбор времени;
- `/cancel_booking` — отмена ближайшей будущей записи;
- `/help` — краткая справка;
- `/cancel` — выход из текущего диалога.

Запись также можно отменить сообщением `Отменить запись`.

## Команды мастера

- `/add_slot` — добавить свободные интервалы;
- `/slots` — показать будущие интервалы и их статусы.

Формат добавления:

```text
15.08.2026 10:00-11:30
15.08.2026 12:00-13:30
```

Можно отправить несколько строк одним сообщением. После добавления отправьте
`Готово`.

## Настройки

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота | обязательна |
| `MASTER_TELEGRAM_ID` | Telegram ID мастера | обязательна |
| `DATABASE_PATH` | Путь к SQLite | `data/database.db` |
| `LOG_PATH` | Путь к журналу | `logs/bot.log` |
| `LOG_LEVEL` | Уровень журнала | `INFO` |
| `TIMEZONE` | Часовой пояс расписания | `Europe/Moscow` |
| `MAX_APPOINTMENTS_PER_DAY` | Дневной лимит | `6` |
| `REMINDER_MINUTES` | Время напоминания | `15` |
